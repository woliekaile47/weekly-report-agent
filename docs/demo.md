# 五分钟演示流程

演示前启动应用，准备一个真实模型生成且停在 REVIEW 的任务。这样现场不依赖临时网络速度。

| 时间 | 操作 | 展示内容 |
|---|---|---|
| 0:00–0:40 | 展示任务表单和样例数据 | 周期、数据、纪要、重点问题 |
| 0:40–1:30 | 打开准备好的任务 | 区域图表、Word、纪要引用、质检记录 |
| 1:30–2:40 | 退回华东区原因说明 | 同一任务版本递增、意见保存、重新送审 |
| 2:40–3:20 | 通过当前版本 | 完整交付包、审核人、文件摘要 |
| 3:20–4:00 | 创建缺纪要任务再补齐 | 暂停原因清楚，补充后继续 |
| 4:00–5:00 | 展示故障与恢复测试结果 | 重试上限、失败步骤、重启不重复已完成步骤 |

网络不可用时改用明确标记的离线演示模式，不能将其作为真实模型表现。

工具故障演示命令：

```powershell
.\.venv\Scripts\python.exe scripts\fault_demo.py
```

进程退出恢复验证：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_recovery.py -q
```

现场小变更建议：修改 `config/employee.yaml` 的异常阈值、禁用词或正文长度，然后创建新任务，展示配置版本变化。不要在已有审核版本上悄悄替换技能快照。
