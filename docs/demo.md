# 演示与现场操作

正式提交需另录不超过 5 分钟的最新版本演示视频。此前的视频使用旧界面，不能作为本版验收依据；演示时应明确区分真实模型成果与工程测试替身，审核决定由现场人员作出。

现场建议按四条用户路径准备：第44周正常生成并人工审核交付；退回“华东原因不清楚”后查看同任务下一版修改说明；只传第44周纪要，暂停后补销售并继续；工具故障有限重试后暂停，再从检查点恢复。另用第46周只传销售文件，展示实际覆盖范围和暂停提示。审核后核对正式包中的 Word、质检、原文、配置、审核与执行记录。

工具故障演示可在测试工作区运行：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_acceptance.py::test_tool_failure_retries_and_recovers -q
```

该测试对正式MCP网关注入可重复的临时失败，验证三次失败后暂停、新服务实例从失败节点恢复，销售读取不重复。模型仅在此工程测试中使用明确替身，不能把它说成真实模型业务验收。产品工作台没有演示模式、故障注入或自动审核开关。

界面录像可通过 `scripts/record_demo.py` 复现，需要本机Chrome及开发依赖playwright。它仅浏览已保存的真实模型任务，不发模型请求、不提交审核决定。源WebM保存在忽略目录runtime/video，可用FFmpeg转为MP4。

本轮演示更新：运行 `python scripts/demo_tool_failure.py` 可在隔离目录复现真实MCP工具连续失败、有限重试、暂停与恢复，并在调用模型前结束。此脚本不修改生产任务。

最新线上只读录像由 `python scripts/record_online_demo.py` 生成，需本机管理员凭据及已完成样例证据（均位于忽略的runtime目录）。文件为 `runtime/submission/产品演示.webm`，明确标注真实成果回放；不发起新任务，不执行审核。演示内容不替代企业盲测或真实人工审批。
